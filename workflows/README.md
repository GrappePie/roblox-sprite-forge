# Workflow incluido

`flux2-klein-4b-distilled-api.example.json` está en el formato API de ComfyUI. El servidor construye una copia equivalente para cada frame y sustituye:

- Imagen de referencia.
- Prompt.
- Seed.
- Resolución.
- Pasos.
- Prefijo de salida.
- Nombres de los modelos.

El grafo usa solamente nodos del núcleo de ComfyUI. Para inspeccionar la versión visual oficial, abre **Workflow Templates** y busca **Flux.2 Klein 4B Distilled: Image Edit**.
